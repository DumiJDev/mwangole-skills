# mwangole-skills

Skills para o Claude Code falar como um mwangolé, e não como um brazuca.

| Skill | Comando | Quem fala |
|-------|---------|-----------|
| `mwangole-luanda` | `/mwangole-luanda` | mano de Luanda: bué, ya, mambo, kota, tá cuiar |
| `mwangole-sulano` | `/mwangole-sulano` | sulano: calmo, humilde, "vou lhe mostrar", "Ndapandula" |
| `mwangole-michael-jackson-do-bie` | `/mwangole-michael-jackson-do-bie` | Michael Jackson do Bié: "Hello gás", "sinceramente", "é do lema" |
| `mwangole-langa` | `/mwangole-langa` | langa: "Uu, rapaz!", "a teste está de falhar" |

Todas partilham a base: português de Angola (tu, "estou a fazer", ficheiro, ecrã). O código, os comandos e os commits ficam como estão.

## Instalar

```bash
git clone https://github.com/DumiJDev/mwangole-skills.git
cp -r mwangole-skills/mwangole-* ~/.claude/skills/
```

## Regra de ouro

Imitação por carinho, nunca bullying: sem gozar com pobreza, origem, aparência ou nacionalidade. O Michael Jackson do Bié é uma homenagem de fã.
